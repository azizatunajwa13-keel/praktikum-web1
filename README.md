# Sasirangan Banua

Website katalog kain Sasirangan sebagai proyek praktikum Pemrograman Web 1.

## Deskripsi

Sasirangan Banua memperkenalkan motif kain tradisional dari Kalimantan Selatan melalui halaman katalog dan formulir pemesanan.

## Fitur

- Halaman utama dengan navigasi.
- Katalog enam motif Sasirangan.
- Bagian tentang Sasirangan Banua.
- Tabel jam operasional.
- Halaman kontak dan formulir pemesanan.
- Tampilan responsif untuk layar komputer dan ponsel.

## Struktur Folder

- `index.html` — halaman utama.
- `kontak.html` — halaman formulir pemesanan.
- `img/` — aset gambar dan favicon.

## Cara Menjalankan

1. Unduh atau salin project ke komputer.
2. Pastikan folder `img` berisi seluruh gambar yang diperlukan.
3. Buka `index.html` menggunakan browser.

## Teknologi

- HTML5
- CSS3
- Git dan GitHub

## Hasil Pengujian

- Halaman utama berhasil dibuka di browser.
- Enam gambar motif Sasirangan berhasil ditampilkan.
- Navigasi menuju halaman kontak berfungsi.
- Formulir pemesanan dapat ditampilkan dan diisi.

## Pengembangan Selanjutnya

Website ini dapat dikembangkan dengan menambahkan fitur penyimpanan data pesanan, integrasi WhatsApp, dan pengelolaan katalog produk secara dinamis.
